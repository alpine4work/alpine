## Conventions

- Identifiers are 26-character lowercase base32 strings, e.g. <ExampleId />. Each
  resource has its own typed id (<TypeLink name="DocumentId" />,
  <TypeLink name="TaskId" />, and so on).
- Timestamps are ISO 8601 strings, the <TypeLink name="DateTime" /> type.
- Rich text everywhere (documents, messages, posts, task notes) uses the
  recursive <TypeLink name="Content" /> model.
- List endpoints are cursor-paginated via `cursor` and `nextCursor`.
