## Anatomy of a task

A task has a title, a status, and optional assignee, due date, priority, and rich-text notes.
Tasks can be grouped into collections and nested under a parent.

| Field    | Values                                          |
| -------- | ----------------------------------------------- |
| Status   | <Kbd>Open</Kbd> <Kbd>Closed</Kbd>               |
| Priority | <Kbd>Low</Kbd> <Kbd>Medium</Kbd> <Kbd>High</Kbd> <Kbd>Urgent</Kbd> |
| Assignee | Any member of the space                         |
| Notes    | Rich text — the same editor as documents        |

## A simple workflow

<Steps>
<Step title="Capture">Create a task with <Kbd>C</Kbd> then <Kbd>T</Kbd>, or from any message via the ⋯ menu.</Step>
<Step title="Triage">Set a priority and assignee so it shows up in the right person's list.</Step>
<Step title="Track">Group related tasks into a collection to see them as a board or list.</Step>
<Step title="Close">Mark it Closed — it stays searchable and linked wherever it was mentioned.</Step>
</Steps>
