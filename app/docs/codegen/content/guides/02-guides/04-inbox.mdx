## Entry types

The inbox merges chats, channel posts, document threads, and task activity into a single stream.
Each entry is either New or Done, and loud notifications (like mentions) are counted so you can
see what's urgent at a glance.

| Entry            | Comes from                     |
| ---------------- | ------------------------------ |
| Chat             | A direct or group chat message |
| Post             | A new channel post             |
| Document thread  | A comment thread on a document |
| Task activity    | Activity on a task you follow  |

<Callout type="info" title="Personal to you">
    The inbox is yours alone — each person has their own inbox in every space they belong to.
</Callout>
