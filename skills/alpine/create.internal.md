# What can you create in Alpine?

To create something in Alpine, pass one of the listed `type`s below to the `create` tool along with
the markdown content for the new page. Read the link to learn more about the markdown format for
each type.

- [`document`](documents.internal.md)
- [`document-comment-thread`](document-comments.internal.md)
- [`chat`](chat.internal.md)
- [`channel`](forum.internal.md)
- [`post`](forum.internal.md)
- [`task`](tasks.internal.md)
- [`task-collection`](tasks.internal.md)

Some things you can only create by using the `update` tool, read the associated link to learn more:

- [Chat messages and comments](messaging.internal.md)

Some things you can't create right now:

- Humans and bots: You can't invite new people to the space, a human must do this.
- Spaces: Companies should only have one space. Creating a new space is rare, a human should do it.
- Files: You can't upload arbitrary files right now, we're working on adding support for this.
