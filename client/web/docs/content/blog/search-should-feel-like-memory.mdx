Search is often treated like a utility drawer. Type a word, get a list, sort by
text relevance, and hope the result you meant is in the first few rows.

Work search can do better because it has more signal. Recency matters. Affinity
matters. The project you keep opening this week matters.

## Ranking the working set

Our goal is for search to feel less like querying a database and more like
recovering a thought. That takes indexing, permissions, embeddings, and a lot of
small ranking decisions that should disappear when they are working.
