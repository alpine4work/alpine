The most useful work graph is not a diagram people maintain by hand. It is the
shape that appears when documents, tasks, conversations, and search all point at
the same underlying context.

When those references are durable, a task can explain why it exists, a document
can show the decisions that shaped it, and search can recover the path back to a
team's intent.

## Connected by default

The product challenge is making those connections feel automatic without making
the interface feel busy. References should appear where they help people decide,
not everywhere a database relationship happens to exist.

![A connected map of Alpine work surfaces](/blog/images/editor-pattern.svg)

That balance is what turns a pile of records into a system people can navigate.
