Most projects begin in prose and end in lists. The awkward part is everything in
between: copying decisions into tickets, linking tasks back to plans, and trying
to remember which thread changed the scope.

## One shared trail

When documents and tasks live together, the trail is easier to follow. A task can
carry the note that created it. A document can show the work it spawned. Comments
can stay attached to the thing they are actually about.

That is not just cleaner navigation. It changes how much context the team has to
reload every morning.
