## Everything is a block

A document is an ordered list of blocks: paragraphs, headings, lists, quotes, tables, code,
files, and previews. Blocks can nest — a table cell or a quote can contain more blocks — so your
structure can be as simple or as deep as the work needs.

## Mentions & threads

Type <Kbd>@</Kbd> to mention a person, document, task, or channel. Mentions render as indigo
pills and keep a live link to their target. Select any text and comment to start a thread —
resolved threads collapse out of the way.
