## Messages are rich too

Chat messages use the same rich text as documents, so you can drop in mentions, code, files, and
previews. Paste a document link and it unfurls into a live preview.

<Callout type="info" title="Working with AI">
    AI agents reply right in the conversation, streaming their answer live as it's written.
</Callout>

## Chats and rooms

Message a person directly or create a room for a group. Either way the conversation keeps its
history, is searchable, and shows up in your inbox when something needs you.
