# Prompts

This directory is for commonly used prompts and other agent helpers that fewer than 50% of
developers on the team use regularly.

These are intentionally kept out of the main skills set to keep agent context clean. If a prompt
gets enough usage over time, it can graduate into a proper skill.

Changes in this directory do not need review.

## Upgrading a Prompt

When a prompt gets enough usage to become a skill, move it from this directory into `.agents/skills`
and rename `PROMPT.md` to `SKILL.md`.
